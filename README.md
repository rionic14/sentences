# 문장외우기

영상과 문장을 등록하고 8회에 걸쳐 간격 반복하는 모바일 우선 웹 서비스입니다. 하루는 한국 시간 오전 4시에 바뀝니다.

영상 없이 문장만 먼저 등록할 수 있으며, 데이터 관리 화면에서 영상을 나중에 추가하거나 교체할 수 있습니다.
데이터 관리 화면에서는 현재 회차와 남은 일수를 수정하고, 회차별·누적 반복 진행을 확인할 수 있습니다.
목록은 목표 반복횟수가 많은 순으로 표시하며, 목표가 같으면 복습일이 가까운 문장을 먼저 표시합니다.

## 실행

```bash
cp .env.example .env
npm install
npm start
```

브라우저에서 `http://localhost:3000`을 엽니다.

## Docker Compose

`.env`의 `DATA_VOLUME_PATH`에는 호스트에서 데이터베이스와 영상 파일을 보관할 디렉터리를 지정합니다.

```bash
cp .env.example .env
docker compose up -d --build
```

컨테이너 내부에서는 해당 경로를 `/data`로 마운트합니다. DB는 `sentences.sqlite`, 영상은 `videos/`에 저장됩니다.

## 복습 규칙

- 목표 횟수: 1회차 100회, 2회차 50회, 3회차 30회, 4~8회차 10회
- 다음 회차까지: 1, 4, 8, 16, 32, 64, 128일
- 목표 달성 즉시 회차 완료를 저장하고 다음 문장으로 이동
- 8회차 목표 달성 시 최종 완료
- 복습 대상은 예정일이 오늘이거나 지난 문장이며, 가장 오래 지난 문장을 먼저 표시
